# Product Requirements Document (PRD)

## 1. Product overview

Imamu Qaloon Academy (IQA) is a digital platform that helps the academy present its educational offer, convert inquiries into enrollments, and manage leads efficiently. The product blends a premium educational brand experience with operational administration for the academy team.

## 2. Product vision

Provide a trustworthy, professional, and accessible digital front door for Islamic education that is easy to use on desktop and mobile and supports the academy’s admissions and learner management process.

## 3. Target users

### Primary users
- Prospective learners and parents
- Current or future academy students
- People seeking Quran, Arabic, and Islamic studies support

### Internal users
- Academy admin
- Front desk or admissions team
- Management staff reviewing student inquiries

## 4. Business goals

- Increase trust and brand credibility
- Present IQA programs clearly and professionally
- Capture student inquiries from web visitors
- Support staff follow-up and enrollment tracking
- Create a streamlined lead management system
- Maintain responsive and modern design standards

## 5. Functional requirements

### Public website requirements
- Display the academy brand, mission, and value proposition
- Show core educational offerings and learning tracks
- Provide contact and admissions sections
- Offer WhatsApp contact or inquiry handoff
- Ensure mobile and desktop responsiveness
- Support dark and light theme modes
- Maintain a premium and professional design aesthetic

### Contact and lead capture requirements
- Validate required user input
- Capture name, email, phone, learner type, program, and message
- Save lead records securely in local storage/database
- Trigger an email alert to the academy inbox
- Provide an admin dashboard to view all leads
- Support filtering and status updates

### Admin functionality requirements
- Admin login with protected routes
- View all submitted leads
- Search and filter by name, email, or program
- Update lead status
- Delete incorrect or duplicate entries
- Export workbook data for reporting and follow-up
- Maintain a serial or index count for lead listing

## 6. Non-functional requirements

- Fast page load times
- Responsive design for mobile, tablet, and laptop
- Clear and readable typography
- Secure admin access with session-based protection
- Structured error handling for form submission
- Clean and maintainable code structure

## 7. User journeys

### New visitor journey
1. Visitor lands on homepage
2. User explores programs and academy story
3. User fills contact or admissions form
4. System validates input
5. Lead is saved and admin is notified
6. Admin reviews and follows up

### Admin journey
1. Admin enters login credentials
2. Admin accesses protected dashboard
3. Admin searches and updates lead status
4. Admin exports relevant records
5. Admin deletes or corrects incorrect entries

## 8. Success metrics

- Higher inquiry conversion from website visitors
- Reduced manual follow-up burden
- Faster response time to new leads
- Clean and searchable lead archive
- Consistent digital brand experience across all pages

## 9. Acceptance criteria

- All public pages load and display correctly on major screen sizes
- Contact form validates data before submission
- A valid inquiry creates a database record
- Admin can log in and access dashboard securely
- Admin can search, update status, and delete leads
- Exported workbook is downloadable and properly structured
- The website appears premium, accessible, and professional
